⚡ Back4App Cloud Code ile API Geliştirme Rehberi

📅 25 Ağustos 2026 👤 İbrahim Admin 🏷️ Geliştirici API

Back4App, Parse Server tabanlı bir Backend-as-a-Service platformudur. Cloud Code, sunucu tarafında çalışan JavaScript fonksiyonlarıdır. Bu rehberde, Cloud Code kullanarak nasıl kendi API fonksiyonlarınızı yazacağınızı, test edeceğinizi ve canlıya alacağınızı adım adım anlatacağım.

Öncelikle, Back4App Dashboard'da Cloud Code bölümüne gidin. `main.js` dosyasını düzenleyerek yeni fonksiyonlar ekleyebilirsiniz. Örneğin, basit bir "merhaba dünya" fonksiyonu:

Parse.Cloud.define("hello", async (request) => {
    return "Merhaba, Dünya!";
});

Bu fonksiyonu istemci tarafından `Parse.Cloud.run('hello')` ile çağırabilirsiniz. Daha karmaşık işlemler için, veritabanı sorguları, dış API çağrıları ve dosya işlemleri ekleyebilirsiniz.

Cloud Code'un en büyük avantajı, güvenli bir ortamda çalışmasıdır. API anahtarlarınızı ve hassas bilgileri istemci tarafında değil, Cloud Code içinde saklayabilirsiniz. Ayrıca, oturum kontrolü yaparak yalnızca yetkili kullanıcıların belirli fonksiyonlara erişmesini sağlayabilirsiniz.

Bu rehberde, gerçek dünya örnekleriyle Cloud Code'un tüm inceliklerini öğreneceksiniz. Hata yönetimi, asenkron işlemler, veritabanı ilişkileri ve daha fazlası.

Back4App Cloud Code, ölçeklenebilir ve güvenilir bir arka uç çözümüdür. Vizyon2027'nin tüm arka uç işlemleri Cloud Code üzerinden çalışmaktadır. Siz de kendi projelerinizde bu güçlü aracı kullanabilirsiniz.

🔒 Veri Güvenliği ve Gizlilik Politikası

📅 30 Ağustos 2026 👤 Vizyon Ekibi 🏷️ Güvenlik Yasal

Vizyon2027 olarak, kullanıcılarımızın verilerinin güvenliği bizim için en önemli önceliktir. Bu yazıda, hangi verileri topladığımızı, nasıl kullandığımızı ve hangi haklara sahip olduğunuzu şeffaf bir şekilde açıklıyoruz.

Toplanan Veriler: E-posta adresi, kullanıcı adı, AI sorguları, takım mesajları, cihaz bilgileri (cihaz modeli, işletim sistemi).

Toplanmayan Veriler: Konum (yalnızca IP adresi, konum bilgisi toplanmaz), fotoğraflar, rehber, SMS, arama kayıtları, biyometrik veriler, finansal bilgiler. Bu veriler kesinlikle toplanmaz.

Veri Kullanımı: Toplanan veriler, yalnızca hizmet kalitesini artırmak, size özel deneyim sunmak ve platformu geliştirmek için kullanılır.

Veri Paylaşımı: Hiçbir 3. tarafla paylaşılmaz, satılmaz veya kiralanmaz.

Veri Saklama: Hesabınız aktif olduğu sürece verileriniz saklanır. Hesap silindiğinde, tüm verileriniz kalıcı olarak yok edilir.

Kullanıcı Hakları: KVKK ve GDPR kapsamında, verilerinize erişme, düzeltme, silme (unutulma hakkı), işlemeye itiraz etme ve veri taşınabilirliği haklarına sahipsiniz.

Detaylı bilgi için Gizlilik Politikası sayfamızı ziyaret edebilirsiniz.
