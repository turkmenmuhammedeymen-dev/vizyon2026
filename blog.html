Veri Güvenliği: AES-256-GCM + PBKDF2 Şifreleme

📅 16 Eylül 2026 👤 AETHRION Ekibi
Güvenlik Yasal

Tüm API anahtarları AES-256-GCM ile şifrelenir. API şifreleri PBKDF2-SHA512 (100.000 iterasyon) ile hash'lenir. A27 API anahtarları SHA-256 ile korunur. Rate limiting (in-memory + persistent) aktif. XSS koruması, içerik filtreleme, Vizyon Devriye (7/24) tüm güvenlik katmanları mevcut.
