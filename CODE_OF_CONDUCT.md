# AETHRION Community Code of Conduct

Be respectful, specific and constructive. Critique ideas/code rather than personal traits. Respect privacy, credit third-party work and disclose security issues privately.

Harassment, threats, discriminatory abuse, doxxing, impersonation, credential theft, unauthorized access and deliberate disruption are not acceptable.

Report concerns through https://vizyon2026.vercel.app/iletisim.html or aethrion.official@gmail.com, sharing only necessary context.
