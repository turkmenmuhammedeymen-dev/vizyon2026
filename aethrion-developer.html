API belgeleri

Mevcut AI sohbet uç noktası: Parse.Cloud.run("v27ApiRest", { apiKey, prompt, lang }). Uygulama anahtarı tarayıcı koduna veya herkese açık depoya gömülmemelidir.

JavaScript örneği (sunucu tarafında kullan)

const result = await Parse.Cloud.run("v27ApiRest", {
  apiKey: process.env.AETHRION_API_KEY,
  prompt: "Merhaba",
  lang: "tr"
});

İzin modeli

  • chat: sohbet uç noktası için zorunludur.
  • usage:read: anahtara ait kullanım sayacı ve son kullanım bilgisini okumak için zorunludur.
  • İzinler anahtar oluşturulurken sunucuda saklanır ve her istekte kontrol edilir.

Kota: hesap için mevcut anahtar limiti ve mevcut rate limit uygulanır. Henüz ayrı ücretlendirme/billing kotası sunulmuyorsa bu sayfa bunu varmış gibi göstermez.
