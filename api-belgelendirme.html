A27 API Belgeleri

API entegrasyon rehberi

Şeffaflık notu: Endpoint, fonksiyon adı, parametre, kimlik doğrulama biçimi, kota ve model sağlayıcı erişimi gerçek Cloud Code/Parse yapılandırmasıyla doğrulanmalıdır. Bu belge tek başına bir entegrasyonun etkin olduğunu kanıtlamaz. Bu belge, gerçek hizmet yapılandırmasıyla birlikte değerlendirilmelidir.

1. Kapsam ve amaç

Bu sayfa A27 API entegrasyonunu belgelemek için temel bir çerçevedir. Yalnızca etkin ve doğrulanmış uç noktalar üretim dokümantasyonuna eklenmelidir.

2. Uygulama ve sorumluluklar

Üretim öncesi kontrol listesi: temel URL, sürüm, kimlik doğrulama, istek/yanıt şemaları, hata kodları, kota ve limitler, zaman aşımı, yeniden deneme politikası, veri saklama ve sağlayıcı bağımlılıkları.

3. Kullanıcıların dikkat etmesi gerekenler

API anahtarlarını HTML/JavaScript istemci koduna, ekran görüntülerine veya depoya koymayın. Gizli anahtarlar sunucu tarafında saklanmalı; sızıntı durumunda iptal ve yenileme süreci uygulanmalıdır.

4. Şeffaflık ve güncellemeler

Hizmetler veya entegrasyonlar değiştiğinde bu sayfa gözden geçirilmelidir. Yürürlük tarihi, son güncelleme tarihi ve sorumlu işletmeci bilgileri yayına çıkmadan önce eklenmelidir.

5. İletişim

Başvurular için İletişim ve Başvuru sayfasını kullanın.

6. API erişiminin doğrulanması

Üretime geçmeden önce base URL, Cloud Code fonksiyon adları, istek alanları, hata cevapları, kimlik doğrulama ve izin kontrollerini canlı backend yapılandırmasıyla karşılaştırın.

7. Örnek kod ve sürümleme

Örnek çağrıları önce test ortamında çalıştırın. Parse SDK veya Cloud Code imzası değişirse istemci kodunu birlikte güncelleyin ve mevcut sürümle geriye dönük uyumluluğu test edin.

8. Gizli anahtarların korunması

Özel anahtarları, parolaları ve sağlayıcı tokenlarını HTML, tarayıcı JavaScript'i, herkese açık depo, günlük kaydı veya ekran görüntüsüne eklemeyin. Sızıntı şüphesinde anahtarı iptal edin.

Güvenlik ve oran sınırlaması

API ve Cloud Code işlemleri sunucu tarafı kimlik doğrulama, girdi doğrulama, oran sınırlaması ve bağlantı itibarı kontrollerine tabi olabilir. API anahtarları istemci kodunda veya herkese açık depolarda saklanmamalıdır. VPN/proxy tespiti sağlayıcı verisine dayanır ve kesin sonuç garantisi vermez.
