## Root layout
Vercel currently deploys static files from the repository root; there is no `public/` directory. Main files include `index.html`, `logo.svg`, `favicon.svg`, `aethrion-brand.css`, `robots.txt`, `sitemap.xml`, `site.webmanifest`, `security.html`, `gizlilik.html`, `kullanici-sozlesmesi.html`, `api.html` and `dokumantasyon.html`.

## Release checklist
1. Use a feature branch and review the diff.
2. Run available HTML/JS/CSS checks.
3. Test authentication, permissions, Back4App Cloud Code, AI-provider errors, uploads and microphone access.
4. Verify assets and key pages after Vercel deployment.
5. Use Google Search Console URL Inspection; indexing is not immediate.
6. Never commit API keys, master keys, session tokens or private user data.

The eight-layer security model is a checklist, not an independent audit or proof that every control is enabled. Review actual data flows, subprocessors, retention, age requirements and legal obligations with qualified professionals before commercial launch.
