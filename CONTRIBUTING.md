# Contributing to AETHRION

Find all callers/dependencies before changing features. Preserve legacy Cloud Code names and DOM hooks unless migration is complete. Never commit API keys, private data, user exports or production configuration. Use small reviewable pull requests. Keep layouts responsive, keyboard-operable and reduced-motion aware. Enforce authorization server-side; treat user files and AI output as untrusted. Test logged-out/logged-in states, denied permissions, provider errors and mobile layouts. State untested areas honestly.
