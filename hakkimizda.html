Geleceği İnşa Ediyoruz

AETHRION, genç ve dinamik bir ekibin hayali olarak doğdu. Amacımız en güçlü yapay zeka teknolojilerini herkesin kullanımına sunmak. 28 AI modeli, AETHRION AI, A27 API ve devrim niteliğinde ekosistemle 2027'ye damga vurmaya hazırlanıyoruz.

🎯 Misyon, Vizyon & Slogan

🎯 Misyonumuz

Yapay zekayı herkes için erişilebilir, anlaşılır ve kullanışlı hale getirmek. 28 farklı AI modelini tek platformda birleştirerek, kullanıcıların dil, kod, analiz, üretim ve öğrenme süreçlerinde en iyi deneyimi yaşamasını sağlamak.

🚀 Başarılarımız

AETHRION kısa sürede devasa bir ekosisteme dönüştü. İşte gurur duyduğumuz başarılarımız:

  • ✓ 28 AI Modeli Tek Çatı: 13 yerli Ollama + 7 Nvidia NIM + 8 bulut API (Groq, Gemini, DeepSeek, DeepInfra, OpenAI, Cerebras, OpenRouter, Cohere) sırayla denenir, en iyi cevap getirilir.
  • ✓ AETHRION AI Paneli (4 Mod): Normal, Derin Düşünme, Ajan, Yazılımcı modları + ekran okuma + sesli sohbet + dosya analizi + indirilebilir sunum.
  • ✓ A27 API Sistemi: Süreli (1h/1a/5a/1y/süresiz), SHA-256 hash'li, AES-256-GCM şifreli anahtar sistemi. Kendi projelerinizde AI gücü.
  • ✓ A27 Koç Asistanı: Samimi, yol gösteren, psikolojik destek veren AI koç. Haftalık limit sistemi + şifreli paylaşım.
  • ✓ Sesli Sohbet: ChatGPT tarzı tam ekran sesli konuşma. Sürekli mod + kesin durdurma.
  • ✓ Dosya Analiz + Sunum: PDF, Word, Excel, görsel, video, ZIP, kod dosyaları. Otomatik sunum + indirme linki.
  • ✓ Logs Sistemi: 5 seviyeli (Info/Success/Warning/Error/Critical) log takibi + backend sync.
  • ✓ Video Stüdyosu: Senaryo, Reels fikirleri, video analiz, kesit aracı. 4 farklı işlem.
  • ✓ 3D Stüdyo (90+ Şekil): Küp, küre, robot, roket, ağaç, kalp ve 90+ hazır 3D model. Sürükle-bırak, .glb indir.
  • ✓ Takım Çalışması: Ortak projeler, takım sohbeti, @AETHRION AI / @vizyondestek komutları, üye yönetimi.
  • ✓ Moderatör Rütbesi: Gizli, sadece kurucu tarafından atanan sınırsız yetkili rütbe.
  • ✓ Vizyon Devriye (7/24): Otomatik moderasyon sistemi. Küfür/argo/siyasi içerik tespit + müdahale.
  • ✓ Plan Limit Sistemi: Free / Pro / Team paketleri. Her özellik için ayrı limitler.
  • ✓ Ebeveyn Kontrolü: Canlı takip, harcama limiti, özellik kapatma, oturum geçmişi, haftalık rapor.
  • ✓ Aylık Yarışma: Ödüllü proje yarışması. 🥇 Takım · 🥈 Pro · 🥉 5000 puan.
  • ✓ A27 Akademi: Kod, 3D, veri analizi, güvenlik ve A27 API dersleri + quiz.
  • ✓ Güvenlik: AES-256-GCM, PBKDF2-SHA512, SHA-256, SSL/TLS, rate limiting, XSS koruması.
