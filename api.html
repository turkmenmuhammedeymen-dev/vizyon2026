📡 Back4App Cloud Code ⚡ Tüm Fonksiyonlar Çalışır

Vizyon2027 API, Back4App Cloud Code üzerinden çalışan güçlü bir arka uç hizmetidir. Tüm fonksiyonlara Parse SDK ile JavaScript üzerinden erişebilirsiniz.

// 📦 Parse SDK ile API çağrısı örneği
const result = await Parse.Cloud.run('superAI', {
  prompt: 'Python'da REST API nasıl yazılır?'
});
console.log(result);

👤 Kullanıcı Yönetimi

  • register – Yeni kullanıcı kaydı
  • login – Kullanıcı girişi
  • verifyUser – E-posta doğrulama
  • sendVerificationCode – Doğrulama kodu gönder
  • resetPasswordWithCode – Şifre sıfırlama
  • getProfile – Profil bilgilerini getir
  • searchUsers – Kullanıcı ara
  • toggleFollow – Takip et / bırak

👥 Takım Yönetimi

  • createTeam – Takım oluştur
  • joinTeamWithCode – Kod ile takıma katıl
  • sendTeamMessage – Takım mesajı gönder
  • inviteToTeam – Takıma davet et
  • getTeamMembers – Takım üyelerini listele
  • makeTeamManager – Yönetici ata
  • transferOwnership – Sahipliği devret
  • leaveTeam – Takımdan ayrıl
  • closeTeam – Takımı kapat

📦 Proje ve Ürün Yönetimi

📖 Örnek Kullanımlar

1. AI Sorgusu Gönderme

// 🤖 VİZYON AI'ya soru sor
const response = await Parse.Cloud.run('superAI', {
  prompt: 'React'te bir todo uygulaması nasıl yapılır?'
});
console.log(response);

2. Web Arama Yapma

// 🌐 Dolar kuru veya haber ara
const result = await Parse.Cloud.run('webSearch', {
  query: 'bugün dolar ne kadar'
});
console.log(result);

3. Takım Mesajı Gönderme

// 👥 Takım sohbetine mesaj at
const result = await Parse.Cloud.run('sendTeamMessage', {
  teamId: 'TEAM_ID',
  message: 'Merhaba takım!'
});
console.log(result);

4. Yorum Ekleme

// 💬 Yorum gönder
const result = await Parse.Cloud.run('addComment', {
  comment: 'Harika bir uygulama!',
  rating: 5
});
console.log(result);

🔐 Güvenlik ve Limitler

  • Kimlik Doğrulama: Çoğu fonksiyon için oturum açmış kullanıcı gerekir.
  • Sorgu Limiti: Ücretsiz kullanıcılar 25 sorgu/gün, Pro kullanıcılar 2000 sorgu/gün, Takım kullanıcıları sınırsız.
  • Admin/Kurucu Yetkisi: Yönetim fonksiyonları yalnızca yetkili kullanıcılar tarafından çağrılabilir.
  • Rate Limit: Aşırı kullanım durumunda geçici olarak erişim kısıtlanabilir.
