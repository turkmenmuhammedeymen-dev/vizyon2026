V27 API Sistemi YENİ

Kendi uygulamalarınızda VİZYON AI gücünü kullanın

🌟 V27 API Nedir? V27 API, VİZYON AI'nın 28 model birleşik gücünü dış uygulamalara açan bir REST API servisidir. Kendi web sitenizde, mobil uygulamanızda, bot'unuzda veya Discord/Telegram entegrasyonunuzda kullanabilirsiniz.

🔐 Güvenlik

  • Anahtar değeri SHA-256 ile hash'lenir, sunucuda düz metin olarak saklanmaz.
  • Kullanıcıya sadece 1 kez tam anahtar gösterilir.
  • Sonrasında sadece maskelenmiş hali görünür: V27-XXXX••••••••-XXXX
  • Her istekte usage_count otomatik artar.
  • Süre dolduğunda anahtar otomatik geçersiz olur.

🌐 REST ile Kullanım (cURL)

Bash curl -X POST "https://vizyon2026.vercel.app/api/v27ApiRest" \ -H "Content-Type: application/json" \ -H "X-V27-Api-Key: V27-XXXX-XXXX-XXXX-XXXX" \ -d '{"prompt": "Merhaba, nasılsın?", "lang": "tr"}'

🐍 Python ile Kullanım

Python import requests class V27Bot: def __init__(self, api_key): self.api_key = api_key self.url = 'https://vizyon2026.vercel.app/api/v27ApiRest' def sor(self, prompt, lang='tr'): response = requests.post( self.url, headers={ 'Content-Type': 'application/json', 'X-V27-Api-Key': self.api_key }, json={'prompt': prompt, 'lang': lang} ) return response.json().get('reply', '') # Kullanım bot = V27Bot('V27-XXXX-XXXX-XXXX-XXXX') cevap = bot.sor('Python ile REST API nasıl yazılır?') print(cevap)
⚠️ Güvenlik Uyarısı API anahtarınızı kimseyle paylaşmayın. Kodunuzda .env dosyası kullanın, hardcode yapmayın. GitHub'a commit'lemeyin. Sızıntı durumunda derhal iptal edin.

🔐 Güvenlik Özellikleri

  • AES-256-GCM: Kullanıcı API anahtarları şifreli saklanır
  • PBKDF2-SHA512: API şifreleri 100.000 iterasyonla hash'lenir
  • SHA-256: V27 API anahtarları hash'lenir
  • Rate Limiting: In-memory + persistent (Back4App)
  • Content Filtering: Argo/küfür/siyasi içerik filtrelenir
  • Vizyon Devriye: 7/24 otomatik moderasyon
  • XSS Koruması: Tüm kullanıcı girdileri escape edilir
⚠️ Rate Limit Aşımı Limit aşıldığında 429 (Too Many Requests) hatası döner. Uygulamanızda retry mekanizması kullanmanız önerilir (exponential backoff).

Tam Örnekler

Gerçek kullanım senaryoları

1. AI Sorgusu + Kaydetme

JavaScript // Sorgu hakkını kullan await Parse.Cloud.run('useQuery'); // AI'ya sor const reply = await Parse.Cloud.run('superAI', { prompt: 'React hook nedir?' }); // Cevabı kaydet const project = await Parse.Cloud.run('saveProject', { name: 'React Hooks Notları', type: 'Kod', content: reply });

2. Takım Oluştur + Mesaj Gönder

JavaScript // Takım kur (Team planı gerekli) const team = await Parse.Cloud.run('createTeam', { name: 'Frontend Ekibi' }); console.log('Takım kodu:', team.teamCode); // AI komutu ile mesaj at await Parse.Cloud.run('sendTeamMessage', { teamId: team.teamId, message: '@vizyonal Python\'da asal sayı bulma kodu yaz' });

3. V27 API ile Kendi Chatbot'unu Yap

JavaScript // 1. V27 API anahtarı oluştur const apiKey = await Parse.Cloud.run('createV27ApiKey', { keyName: 'Web Chatbot', duration: '1y' }); // 2. Anahtarı kaydet (bir kez gösterilir!) localStorage.setItem('v27_key', apiKey.plainKey); // 3. Kendi backend'inden çağır async function chat(message) { const res = await fetch('https://vizyon2026.vercel.app/api/v27ApiRest', { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-V27-Api-Key': localStorage.getItem('v27_key') }, body: JSON.stringify({ prompt: message, lang: 'tr' }) }); return (await res.json()).reply; }

4. Dosya Analizi + Sunum İndir

JavaScript // Dosyayı Base64'e çevir const fileBase64 = await fileToBase64(file); // Analiz et const analysis = await Parse.Cloud.run('vizyonAlFileAnalyze', { fileBase64: fileBase64, fileName: file.name, fileType: file.type, question: 'Bu dosyayı özetle ve sunum haline getir' }); // Sunum oluştur const presentation = await Parse.Cloud.run('vizyonAlFileCreate', { content: analysis.reply, format: 'html', // 'txt' | 'html' | 'md' | 'json' title: 'Dosya Sunumu' }); console.log('İndir:', presentation.fileDownloadUrl);
