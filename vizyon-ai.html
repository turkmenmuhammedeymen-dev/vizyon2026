📌 Sık Sorulan Sorular

VİZYON AI kaç model kullanıyor?
13 yerli Ollama modeli + 8 bulut API = toplam 21 farklı yapay zeka modeli. Hepsi sırayla denenir, ilk başarılı cevabı verir.
AETHRION AI nedir?
21 yapay zekayı tek panelde birleştiren çeyrek ekran AI aracıdır. 4 mod: 🌐 Normal, 🧠 Derin Düşünme, 🕵️ Ajan, 💻 Yazılımcı. Ekran okuma, sesli sohbet, dosya analiz özellikleri vardır.
A27 API anahtarı nasıl alınır?
Dashboard'da "AETHRION Yapay Zekasının API Anahtarı" bölümüne gidin, "Anahtarını Al" butonuna tıklayın, ad + süre seçin. Anahtar sadece bir kez gösterilir, güvenli bir yere kaydedin!
V27 Koç Asistanı nedir?
Çok samimi, yol gösteren, psikolojik destek veren AI koçtur. Haftalık limitler: Free=10, Pro=50, Team=1000, Admin/Beta/Founder/Moderatör=Sınırsız. Sohbetler şifreli link ile paylaşılabilir.
Moderatör / Tasarımcı nasıl olunur?
Bu rütbe satın alınamaz ve butonu yoktur. Sadece Kurucu tarafından mail ile atanır. Ekranı normal üye gibi görünür, ama yetkileri sınırsızdır (Beta ve Admin ile aynı seviye).
VİZYON AI hangi dillerde kod yazabilir?
Python, JavaScript, React, Next.js, HTML, CSS, SQL, Docker, Java, C#, C++, Flutter, React Native ve daha fazlası. Sadece "Python'da hesap makinesi yaz" gibi bir komut vermeniz yeterlidir.
VİZYON AI'nın sorgu limiti nedir?
Ücretsiz: 100/gün · Pro: 2000/gün · Takım: Sınırsız · Admin/Founder/Beta/Moderatör: Sınırsız.
Dosya yükleyebilir miyim?
Evet. PDF, Word, Excel, görsel (fotoğraf), video, ses, ZIP, kod dosyaları — hepsi desteklenir. AI okur, analiz eder, sunum oluşturur ve indirilebilir link verir.
Verilerim güvende mi?
Evet. Tüm API anahtarları AES-256-GCM ile şifrelenir, şifreler PBKDF2-SHA512 ile hash'lenir. Kişisel verileriniz 3. taraflarla paylaşılmaz.
VİZYON AI'yı takım sohbetinde nasıl kullanırım?
Takım sohbetinde @vizyonal yazarak AI'ya, @vizyondestek yazarak Vizyon Destek asistanına, @v27 yazarak A27 API bilgilerine ulaşabilirsiniz.
