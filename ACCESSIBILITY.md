# AETHRION Accessibility Statement

AETHRION aims to support different screen sizes, input methods and assistive technologies. This is an ongoing goal, not a claim of completed certification or full conformance with a specific standard.

Goals: semantic headings/landmarks, keyboard controls, visible focus, accessible icon labels, readable contrast, responsive/zoom-friendly content, reduced-motion alternatives and errors that do not rely on color alone.

Report issues to **aethrion.official@gmail.com** with the page, assistive technology/browser and reproduction steps. Do not include sensitive account information.
